# Spark — حاسبات الكهرباء

حاسبات كهرباء أوفلاين (Android WebView):
- مقطع الكابل والقاطع المناسب (كتالوجات السويدي وبحره 0.6/1kV + معاملات التخفيض لكل مصنّع)
- نسبة ملء المواسير والتراي والترنك (الكود المصري 40% / NEC للسعودية)
- تقدير الأحمال بالمتر المربع (SEC DPS Dec 2022 / ضوابط شركات التوزيع في مصر)
- هبوط الجهد
- تيار القصر (IEC 60909 مبسطة) والتحمل الحراري للكابل
- اختيار الـ Busway (بحره TBS نحاس/ألومنيوم): المقنن حسب الحرارة، هبوط الجهد، Icw
- تصدير كل الحسابات لملف Excel (شيت لكل حاسبة)

الصفحة في `app/src/main/assets/index.html`، وبيانات بحره في `data-bahra.js` (تتولّد بـ `tools/extract_bahra.py` من نص الكتالوجات)، وكاتب Excel في `xlsx.js`. المراجع وحالتها في `docs/REFERENCES.md`. أي push على main يبني APK وينشره في Releases ▸ latest.
